# Project Name

FoodExpress

## Description

Мобильное приложение-агрегатор ресторанов для заказа еды. Пользователь может просматривать меню, выбирать блюда, изменять их характеристики и количество, добавлять товары в корзину и оформлять заказ. При оформлении заказа доступен выбор способа оплаты: онлайн, ЕРИП, терминал или наличные, а также указание адреса доставки и комментария к заказу. Приложение определяет местоположение пользователя и предлагает ближайший ресторан из выбранной категории на карте. Реализована регистрация пользователей. Данные о пользователях, заказах и меню хранятся в базе данных SQLite, настройки сохраняются в UserDefaults. Приложение локализовано на английский, русский и белорусский языки.

## Installation

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/iamglebik/tpmp-lab9.git
   ```
2. Перейдите в папку проекта и откройте файл `FoodExpress.xcodeproj` в Xcode (версия 15.0 или выше).
3. Дождитесь завершения загрузки зависимостей Swift Package Manager.
4. Выберите целевое устройство (симулятор iPhone 15 Pro или подключённое устройство с iOS 17.0+).
5. Нажмите кнопку Run для сборки и запуска приложения.

## Usage

После запуска приложения пользователь попадает на экран авторизации. Необходимо зарегистрироваться, указав email и пароль, либо войти под существующей учётной записью.

На главном экране отображается список ресторанов и категории блюд. Пользователь может:
- выбрать ресторан и перейти к просмотру меню;
- фильтровать блюда по категориям;
- добавлять блюда в корзину, изменяя их количество;
- открыть карту для выбора ресторана по геолокации;
- перейти в корзину для оформления заказа.

На экране оформления заказа необходимо:
- проверить состав корзины и итоговую сумму;
- выбрать способ оплаты;
- указать адрес доставки;
- при необходимости добавить комментарий к заказу;
- подтвердить заказ.

## Branching Strategy

- `main` — стабильная версия, готовая к сдаче. Пушить напрямую запрещено, только через Pull Request из `development`.
- `development` — основная ветка разработки. Все фичи сливаются сюда.
- `feature/*` — ветки для отдельных задач. После завершения сливаются в `development` через Pull Request.
