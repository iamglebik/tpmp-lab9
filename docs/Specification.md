# Спецификация требований. FoodExpress

## 1. Назначение приложения

FoodExpress — мобильное приложение-агрегатор ресторанов для заказа еды с доставкой. Пользователь может просматривать меню ресторанов, фильтровать блюда по категориям, добавлять блюда в корзину, оформлять заказ с выбором способа оплаты и указанием адреса доставки. Приложение определяет местоположение пользователя и отображает ближайшие рестораны на карте. Сервис поддерживает регистрацию пользователей. Данные хранятся локально в базе данных SQLite, настройки — в UserDefaults. Приложение локализовано на английский, русский и белорусский языки.

## 2. Общее описание

### 2.1. Пользователи

- Клиенты сервиса доставки еды.
- Пользователи с устройствами на iOS 17.0 и выше.

### 2.2. Требования к программному обеспечению

- Целевая платформа: iOS 17.0 и выше.
- Среда разработки: Xcode 15.0 и выше.
- Язык программирования: Swift 5.9+.
- Фреймворк интерфейса: SwiftUI.
- Архитектура: MVVM.
- База данных: SQLite (библиотека SQLite.swift).
- Локальное хранилище настроек: UserDefaults.

### 2.3. Требования к аппаратному обеспечению

- Устройство iPhone с поддержкой iOS 17.0+.
- Наличие модуля GPS для работы геолокации (для симулятора — эмуляция геолокации).
- Доступ к сети Интернет для загрузки картографических данных.

## 3. Спецификация требований

### 3.1. Функциональные требования

**Аутентификация и профиль:**

- FR-01: Регистрация пользователя. Пользователь вводит email, пароль, имя и номер телефона. Данные сохраняются в таблицу `users` базы данных SQLite.
- FR-02: Авторизация пользователя. Пользователь вводит email и пароль. Приложение проверяет наличие записи в БД и при совпадении открывает главный экран.
- FR-03: Выход из учётной записи. Пользователь нажимает кнопку «Выйти», приложение очищает сессию и возвращает экран авторизации.
- FR-04: Просмотр и редактирование профиля. Пользователь видит свои данные (email, имя, телефон) и может их изменять.

**Просмотр меню и блюд:**

- FR-05: Отображение списка ресторанов. На главном экране показываются все доступные рестораны.
- FR-06: Отображение меню ресторана. При выборе ресторана показывается список блюд с фото, названием, описанием и ценой.
- FR-07: Фильтрация блюд по категориям. Пользователь выбирает категорию (Пицца, Суши, Бургеры, Напитки, Всё) — отображаются блюда только этой категории.
- FR-08: Поиск блюд по названию. Поле поиска фильтрует список блюд по введённой подстроке.
- FR-09: Просмотр детальной информации о блюде. Пользователь нажимает на карточку блюда и видит полное описание, состав и цену.
- FR-10: Изменение характеристик блюда. На экране деталей пользователь может выбрать размер порции (маленькая, средняя, большая) и добавки (если применимо).

**Корзина и заказ:**

- FR-11: Добавление блюда в корзину. Пользователь нажимает кнопку «В корзину», блюдо добавляется с указанным количеством.
- FR-12: Просмотр корзины. На экране корзины отображаются все добавленные блюда с количеством, ценой за единицу и общей стоимостью.
- FR-13: Изменение количества блюда в корзине. Кнопки «+» и «-» меняют количество. При количестве 0 позиция удаляется.
- FR-14: Удаление блюда из корзины. Кнопка «Удалить» убирает позицию из корзины.
- FR-15: Расчёт итоговой суммы заказа. Приложение автоматически пересчитывает сумму при изменении корзины.

**Оформление заказа:**

- FR-16: Выбор способа оплаты. Пользователь выбирает один из четырёх способов: Онлайн, ЕРИП, Терминал, Наличные.
- FR-17: Ввод адреса доставки. Пользователь вводит адрес в текстовое поле.
- FR-18: Добавление комментария к заказу. Пользователь вводит текст комментария (необязательное поле, до 200 символов).
- FR-19: Подтверждение заказа. Кнопка «Подтвердить заказ» сохраняет заказ в таблицу `orders`, позиции — в `order_items`, очищает корзину и показывает уведомление об успехе.

**Карта и геолокация:**

- FR-20: Отображение карты с ресторанами. На вкладке «Карта» показывается интерактивная карта с метками всех ресторанов.
- FR-21: Определение текущего местоположения пользователя. Приложение запрашивает доступ к геолокации и показывает положение пользователя.
- FR-22: Определение ближайшего ресторана. Приложение вычисляет расстояние от пользователя до ресторанов и подсвечивает ближайший.
- FR-23: Выбор ресторана через карту. При нажатии на метку ресторана пользователь видит название и может перейти к его меню.

**Локализация:**

- FR-24: Поддержка трёх языков интерфейса. Приложение переведено на английский, русский и белорусский языки. Язык можно переключить в настройках профиля.

### 3.2. Удобство использования

- Интуитивная навигация с помощью TabView (4 вкладки: Меню, Карта, Корзина, Профиль).
- Минимальное количество шагов для оформления заказа (выбрать блюдо -> добавить в корзину -> оформить).
- Понятные сообщения об ошибках валидации (некорректный email, короткий пароль, пустая корзина при попытке оформления).
- Соответствие Apple Human Interface Guidelines.

### 3.3. Требования надёжности

- Валидация всех вводимых данных на стороне клиента перед сохранением.
- Сохранение черновика корзины в UserDefaults (восстановление после перезапуска приложения).
- Корректная обработка отказа в доступе к геолокации (показ сообщения с предложением открыть настройки).
- Корректная обработка пустой базы данных при первом запуске (заполнение тестовыми данными).

### 3.4. Требования производительности

- Загрузка меню из локальной БД: не более 1 секунды.
- Отображение карты с метками: не более 2 секунд.
- Пересчёт корзины при изменении: мгновенно (менее 100 мс).
- Плавная анимация переходов между экранами (60 FPS).

### 4.1. Диаграмма вариантов использования (Use Case)

**Актёр:** Пользователь (Клиент)

**Текстовый сценарий «Оформление заказа» (основной поток):**

| Шаг | Действие пользователя | Реакция системы |
|---|---|---|
| 1 | Нажимает вкладку «Корзина» | Система отображает список добавленных блюд и итоговую сумму |
| 2 | Проверяет состав корзины, нажимает «Оформить заказ» | Система открывает экран оформления |
| 3 | Выбирает способ оплаты (Онлайн / ЕРИП / Терминал / Наличные) | Система подсвечивает выбранный способ |
| 4 | Вводит адрес доставки в текстовое поле | Система сохраняет введённый текст |
| 5 | Вводит комментарий (опционально) | Система сохраняет комментарий |
| 6 | Нажимает «Подтвердить заказ» | Система проверяет, что корзина не пуста и адрес заполнен |
| 7 | — | Система сохраняет заказ в БД, очищает корзину |
| 8 | — | Система показывает уведомление «Заказ успешно оформлен» |

**Альтернативный поток (пустая корзина):**

| Шаг | Действие | Реакция |
|---|---|---|
| 6a | Корзина пуста | Система показывает ошибку «Корзина пуста. Добавьте блюда перед оформлением.» |

**Альтернативный поток (не заполнен адрес):**

| Шаг | Действие | Реакция |
|---|---|---|
| 6b | Адрес доставки пуст | Система показывает ошибку «Введите адрес доставки» |

### 4.3. Физическая модель базы данных (SQLite)

**Таблица `users`:**

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| id | INTEGER | PRIMARY KEY, AUTOINCREMENT | Уникальный идентификатор |
| email | TEXT | UNIQUE, NOT NULL | Email пользователя |
| password_hash | TEXT | NOT NULL | Хеш пароля |
| name | TEXT | NOT NULL | Полное имя пользователя |
| phone | TEXT | NOT NULL | Номер телефона |

**Таблица `restaurants`:**

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| id | INTEGER | PRIMARY KEY, AUTOINCREMENT | Уникальный идентификатор |
| name | TEXT | NOT NULL | Название ресторана |
| latitude | REAL | NOT NULL | Широта |
| longitude | REAL | NOT NULL | Долгота |
| cuisine_type | TEXT | NOT NULL | Тип кухни |

**Таблица `dishes`:**

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| id | INTEGER | PRIMARY KEY, AUTOINCREMENT | Уникальный идентификатор |
| name | TEXT | NOT NULL | Название блюда |
| description | TEXT | NOT NULL | Описание блюда |
| price | REAL | NOT NULL | Цена в BYN |
| category | TEXT | NOT NULL | Категория (Пицца, Суши...) |
| image_name | TEXT | | Имя файла изображения в Assets |
| restaurant_id | INTEGER | FOREIGN KEY -> restaurants(id), NOT NULL | Связь с рестораном |

**Таблица `orders`:**

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| id | INTEGER | PRIMARY KEY, AUTOINCREMENT | Уникальный идентификатор |
| user_id | INTEGER | FOREIGN KEY -> users(id), NOT NULL | Пользователь |
| restaurant_id | INTEGER | FOREIGN KEY -> restaurants(id), NOT NULL | Ресторан |
| status | TEXT | NOT NULL, DEFAULT 'new' | Статус заказа |
| payment_method | TEXT | NOT NULL | Способ оплаты |
| delivery_address | TEXT | NOT NULL | Адрес доставки |
| comment | TEXT | | Комментарий к заказу |
| total_amount | REAL | NOT NULL | Итоговая сумма |
| created_at | TEXT | NOT NULL | Дата и время создания |

**Таблица `order_items`:**

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| id | INTEGER | PRIMARY KEY, AUTOINCREMENT | Уникальный идентификатор |
| order_id | INTEGER | FOREIGN KEY -> orders(id), NOT NULL | Связь с заказом |
| dish_id | INTEGER | FOREIGN KEY -> dishes(id), NOT NULL | Связь с блюдом |
| quantity | INTEGER | NOT NULL, DEFAULT 1 | Количество |
| price_per_unit | REAL | NOT NULL | Цена за единицу на момент заказа |
